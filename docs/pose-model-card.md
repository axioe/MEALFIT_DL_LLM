# 운동 자세 판별 모델 카드

| 항목 | 내용 |
|---|---|
| 기능 | 운동 자세 피드백 (PRD FR-WORK-05 · TRD AI-05 · SDD DL-WORK-01, 5.9) |
| 결정 | D20 자세 판별 운영 기준 (MEALFIT-100) |
| 작성 | 유지훈 · 2026-11-24 |
| 모델 확정 | 2026-11-23, 41종 |

## 1. 하는 일

사용자가 운동을 고르고 촬영하면, 브라우저가 MediaPipe로 관절 좌표를 뽑아 서버로 보낸다. 서버는 운동별 모델로 자세 조건(운동당 3~5개, 전체 167개)마다 "맞음/틀림"을 판정한다.

- 입력: 관절 좌표만. 영상과 사진은 기기 밖으로 나가지 않는다.
- 출력: 조건별 판정과 확률, 조건별 정확도, 모델 버전.
- 판정은 모두 **"참고"** 로 표시한다. 의학적 진단이 아니다.

### 이용 조건 (AI Hub 이용정책·약관·FAQ, 2026-11-24 확인)

- 데이터로 만든 모델·서비스(2차 저작물)는 영리·비영리 모두 활용할 수 있다. 약관에 사용 기간 제한은 없다.
- 출처를 표기한다. 화면 문구: "이 기능은 한국지능정보사회진흥원의 AI 허브 「피트니스 자세 이미지」 데이터(aihub.or.kr)로 학습한 모델을 사용합니다."
- 국외 반출 금지. 해외 서버·클라우드에 저장하는 것도 반출로 본다. 운영 서버는 AWS 서울 리전이다.
- 원본·가공 데이터(이미지, 추출 좌표, 썸네일)는 외부 공개·재배포·제3자 제공을 하지 않는다. git, S3, 발표 자료에 넣지 않는다.

## 3. 모델

- 운동마다 1D-CNN · GRU · HGB · LogReg를 교차검증으로 비교해 가장 나은 모델 하나를 쓴다.
- 구성: 1D-CNN 35종(시드 3개 평균), LogReg 3종, HGB 3종(최원석 v2 모델 2종 포함).
- 최원석 모델 2종(스텝 포워드 다이나믹 런지, 바이시클 크런치)은 입력 특징이 다르다. 같은 관절 좌표를 받아 최원석 `extract_sequence_features`로 특징을 만든다.
- 41종 모두 ONNX로 변환했다. 변환 전후 예측 차이는 최대 6e-5(LogReg), CNN은 1e-6 미만이다.
- 서버 실행에는 onnxruntime(CPU)만 필요하다. TensorFlow와 scikit-learn은 서버에 넣지 않는다.

## 4. 평가

- **교차검증(CV):** 수행자 분리 5-fold, balanced accuracy.
- **외부 평가:** 학습에 쓰지 않은 처음 보는 수행자.
  - AI Hub 검증셋: 맨몸·바벨 7명, 기구 9명. 서서 하는 맨몸 5종은 검증셋에 학습 수행자가 섞여 있어 제외했다.
  - 바벨·덤벨 10–13 묶음은 검증셋이 없어 13번 묶음 수행자 16명을 학습에서 빼고 평가했다. 최종 모델은 4묶음 전체로 다시 학습했다.
  - 맨몸 6종(굿모닝 등)은 검증셋이 없어 CV만 있다.

## 5. 한계

- **연출된 오류:** 라벨이 조합형으로 설계돼 있어, 실제 사용자 영상에서는 정확도가 더 낮을 수 있다.
- **낮은 운동:** 케이블 크런치(외부 0.639), 플랭크(0.671), 바벨 로우(0.672), 버피(CV 0.643)는 0.70 미만이다. 빼지 않고 정확도를 함께 보여 준다 (D20).
- **실제 영상 검증:** 직접 촬영한 푸시업 영상 3개에서 허리 처짐·고개 오류는 맞혔지만, 엉덩이 들림 자세는 놓쳤다. 일부 조건(예: 푸시업 "가슴 충분한 이동")은 영상과 상관없이 같은 값을 냈다.
- **바닥 운동:** MediaPipe가 바닥 자세에서 좌우를 자주 바꿔 인식한다 (PCK@0.2 서 있는 자세 0.922, 바닥 0.514).
- **관측 불가 조건:** 견갑·손가락 키포인트가 없어 "긴장 유지", 숄더 패킹 같은 조건은 간접적으로만 판단한다.
- **보정 없음:** 운동별 0.5 임계값을 그대로 쓰고, 확률 보정은 하지 않았다.
- **외부 평가 없는 15종:** CV 값만 있어 화면에 "교차검증 기준"으로 표시한다.

## 7. 파일 보관 (git에 넣지 않음)

| 파일 | 크기 | 위치 (D20 ①) |
|---|---|---|
| 판정 모델 (운동별 ONNX + manifest.json) | 41종 합계 약 17 MB | 운영 서버 `/opt/mealfit/models/pose/<버전>/`, ai-service에 읽기 전용 연결 (`POSE_MODEL_DIR`) |
| 포즈 모델 `pose_landmarker_heavy.task` · MediaPipe WASM | 약 30 MB | 같은 서버, frontend(nginx)가 정적 파일로 제공. 외부 CDN 미사용 |
| 학습 원본·추출 좌표·중간 파일 | 수백 GB | 유지훈 PC에만 둔다. 서비스와 저장소에 없음 |

- **무결성:** manifest.json의 운동 항목에 파일별 SHA-256(`sha256`)을 기록하면, ai-service가 그 파일을 처음 불러올 때 대조하고 다르면 판정하지 않는다(503 `POSE_003`).
- **버전:** 폴더 이름이 버전이고, 응답의 `modelVersion`에 같은 값을 넣는다. 되돌릴 때는 환경 변수만 이전 폴더로 바꾼다.
- **교체 이력:** 교체 전 모델은 manifest의 `_replaced`에 남긴다 (최원석 모델 2종 교체, 바벨 로우 LogReg → CNN).
- **백업 위치:** 유지훈 PC 원본과 운영 서버 두 곳에만 둔다. S3·공유 드라이브에는 올리지 않는다 (PL 결정). 배포 절차는 `docs/pose-deploy.md`.
