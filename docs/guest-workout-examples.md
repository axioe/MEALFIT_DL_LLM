# 비로그인 운동 예시 데이터 (국민체력100)

| 항목 | 내용 |
|---|---|
| 화면 | 비로그인 운동 둘러보기 (`frontend/src/pages/GuestPage.jsx`의 `GuestWorkout`) |
| 데이터 파일 | `frontend/src/lib/guestWorkoutExamples.js` (스크립트로 만든 파일, 직접 고치지 않음) |
| 작성 | 유지훈 · 2026-11-27 |

## 1. 출처와 이용 조건

- 데이터: 서울올림픽기념국민체육진흥공단 「국민체력100 동영상 정보」 오픈API ([공공데이터포털 15108846](https://www.data.go.kr/data/15108846/openapi.do))
  - 사용한 기능: 운동처방가이드 목록 조회(`TODZ_VDO_TRNG_GUIDE_I`), 운동처방동영상 목록 조회(`TODZ_VDO_TRNG_VIDEO_I`)
- 이용허락범위: 공공누리 제1유형(출처표시). 화면에 출처 문구를 표시한다 (`GUEST_WORKOUT_SOURCE`).
- 운동명·부위·도구·장소·세트·반복횟수·운동시간 텍스트만 쓴다. 동영상·장면 이미지는 이용 조건을 따로 확인하지 않아 쓰지 않는다.
- 서비스 실행 중에는 외부 API를 부르지 않는다. 인증키는 데이터를 만들 때만 쓰고 저장소·운영 서버에 넣지 않는다.

## 2. 고른 기준

| 기준 | 내용 |
|---|---|
| 연령대 | `공통`만 (데이터에 성인 분류가 따로 없음. 청소년·어르신·유소년·유아기 제외) |
| 상체 | 운동부위분류에 상지의 근·가슴의 근·등과 허리의 근 |
| 하체 | 운동부위분류에 하지의 근·골반의 근 |
| 전신 | 상체와 하체 분류가 함께 있는 운동 |
| 제외 | 서비스(집·헬스장 운동 루틴)와 관련 없는 운동: 장소 수영장·실외 전용, 도구 아쿠아봉·킥판·사다리·줄사다리, 2인(짝) 운동, 수영 동작 |
| 정렬 | 세트수·반복횟수·운동시간 중 하나라도 있는 운동을 앞에, 그 안에서 한글 운동명을 영문 운동명보다 앞에, 그다음 운동명 순 |

결과 (2026-11-27 받은 데이터 기준): 상체 120개(세트·횟수 등 있음 36), 하체 126개(31), 전신 36개(9), 제외 31개.
코어는 세부 부위 합의 전이라 화면의 기존 예시(플랭크, 바이시클 크런치)를 그대로 둔다.

## 3. 다시 만드는 방법

1. 공공데이터포털에서 위 API 활용신청 후 인증키(Decoding)를 저장소 밖 파일에 둔다.
2. 두 기능의 전체 목록을 받아(응답 한 행은 운동 영상의 장면 이미지 하나라서 운동명 기준으로 묶는다) 운동명·연령대별로 합치고, 위 기준으로 CSV 2개를 만든다
   (`국민체력100_성인공통_상하체_전체.csv`, `국민체력100_성인공통_상하체_세트횟수있음.csv`).
3. CSV에서 제외 기준을 적용해 `guestWorkoutExamples.js`를 다시 만든다.
4. `cd frontend && npm test`로 `tests/guestWorkout.test.mjs`(부위별 개수, 정렬, 제외 운동 없음)를 확인한다.

받은 원본·CSV·변환 스크립트는 유지훈 PC(`D:\YOOJIHUN\MealFit_pose\kspo_exercises\`)에 있다. 인증키 파일은 저장소에 넣지 않는다.
